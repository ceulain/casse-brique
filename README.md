# Casse-Brique

Un jeu de casse-brique en HTML5 Canvas, sans dépendance.

**Jouer :** https://ceulain.github.io/casse-brique/

## Commandes
- Souris / doigt ou flèches ← → : déplacer la raquette
- Clic / Espace : lancer la balle
- P ou Échap : pause
- M : couper le son

## Bonus
- **W** raquette large · **M** multi-balles · **S** ralenti · **+** vie supplémentaire

5 niveaux, qui recommencent ensuite avec des briques plus résistantes. Le record est gardé dans le navigateur.
